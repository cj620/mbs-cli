# 长时间批量任务执行协议

本协议适用于预计需要多批请求、持续时间较长、结果量未知或需要导出/分析大量明细的任务。数据库、导出和分析 Skill 统一引用本文件，不在各模块重复维护另一套重试、日志或恢复规则。

## 1. 脚本优先

大批量导出或分析应先完成可重复执行的脚本，再由脚本拉取、持久化和处理数据。禁止依赖 Agent 手工复制多批结果，禁止一次性把完整数据集加载到内存。

脚本必须把以下能力集中在一个可测试的任务入口中：

- 稳定游标分页；
- 分批持久化；
- 原子断点；
- 有界重试；
- 结构化日志；
- 继续或重新全量执行的显式选择；
- 最终行数和文件完整性校验。

## 2. 执行前日志与告知

长时间任务在第一次远端请求前必须：

1. 生成唯一任务 ID；
2. 创建独立日志文件、断点文件和中间结果文件；
3. 确认这些路径可写；
4. 告知用户任务 ID、日志路径、断点路径、中间结果路径、最终输出路径、重试上限和恢复策略；
5. 完成上述步骤后才开始查询。

日志采用 NDJSON 等可增量追加的结构化格式，并在每批完成后刷新。至少记录：阶段、批次号、游标摘要、当前批次行数、累计行数、耗时、重试次数、下一次等待时间、断点更新、文件状态和最终校验结果。

禁止在日志中记录 Cookie、Token、密码、完整 SQL、请求/响应正文或业务行数据。错误只记录安全分类、HTTP 状态和脱敏摘要；实际后端错误仍按 CLI 公共输出契约反馈。

## 3. 游标分页

大批量查询优先使用键集游标，不使用不断增大的 `OFFSET`。游标必须：

- 稳定、有序并能唯一定位一行；
- 优先使用主键或唯一键；
- 非唯一时间字段必须追加唯一键组成复合游标；
- `WHERE` 游标谓词与 `ORDER BY` 使用完全相同的字段顺序；
- 每批使用有界 `LIMIT`；
- 下一游标取自已成功持久化批次的最后一行；
- 游标为空、缺列、不前进或重复时立即停止，不得继续循环。

任务开始时应固定查询时间窗口或业务截止时间；源数据可能变化时，脚本还应按业务唯一键去重，并在完成后校验累计行数。

## 4. 分批持久化与断点

每批结果先写入 NDJSON、CSV 或 Parquet 等可恢复中间文件并刷新到磁盘，成功后才原子推进断点。断点至少记录：任务 ID、查询指纹、数据源身份、批次号、下一游标、累计行数、中间文件位置、最后成功时间和任务状态。

恢复前必须校验查询指纹、数据源、脚本版本和输出目标与断点一致。发现中间文件尾部存在未提交数据时，先回退到断点记录的持久化偏移，再继续下一批，避免重复写入。

## 5. 中断后的用户决策

任务因网络、进程退出或设备重启等外部原因中断后，不得静默继续，也不得默认从头查询。应先报告：

- 已完成批次和累计行数；
- 最后成功游标；
- 日志、断点和中间文件路径；
- 中断原因及已有结果是否可恢复；
- 继续执行可能受到的源数据变化影响。

随后要求用户明确选择：

1. 从上一次成功断点继续；
2. 保留旧任务证据，创建新任务并重新全量查询。

查询条件、数据源、表结构、脚本版本或分页契约变化后，旧断点不得直接复用。

## 6. 有界重试

所有任务和子步骤禁止无限重试，也禁止通过递归、重新启动子任务或重置计数变相绕过上限。

- 默认首次失败后最多重试 3 次，即最多尝试 4 次；
- 使用带随机抖动的指数退避，建议从约 1 秒、2 秒、4 秒增长，并设置最大等待上限；
- 同时设置单次请求超时、任务级停止条件和最大批次数；
- 只重试网络中断、超时、HTTP 429、502、503、504 等暂时性错误；
- SQL、参数、权限、认证最终失败、表字段不存在、非只读操作和确定性业务错误不得自动重试；
- 重试耗尽后停止任务，保留已完成结果和断点，及时向用户报告，不得将部分成功标记为完成。

## 7. Excel 流式生成

大量结果导出 Excel 时不得在内存中构造完整工作簿。推荐流程：

```text
分批查询 → 中间文件持久化 → 数据拉取完成 → 流式生成临时 XLSX
→ 关闭 workbook → 校验行数/可打开性 → 原子替换最终文件
```

XLSX 进程中断后通常不能安全原地续写，因此恢复任务应继续中间结果，完成后重新流式生成临时 XLSX。未成功关闭和校验的临时文件不得作为最终结果交付。单个工作表达到 Excel 行数上限前必须自动切换到下一工作表，并为每个工作表重新写入表头。

## 8. 过程反馈

任务应在初始化、试运行通过、批次里程碑、发生错误、安排重试、重试成功、暂停、恢复、数据拉取完成、Excel 生成完成和最终校验时向用户反馈。错误反馈至少包含当前阶段、批次、累计行数、重试次数、下一步和既有结果是否安全保留，但不得逐行输出原始数据。
