# 数据分析规则

## 分析计划

取数前写清：

```text
业务问题：
事实粒度：平台 / 站点 / 店群 / 店铺 / SPU / SKU / Listing / 日期
指标及公式：
维度：
时间范围与时区：
过滤条件：
币种与汇率：
预期决策：
```

## 最低校验

1. 记录行数、列、时间范围、空值、重复键和币种。
2. 对核心指标执行总计与分组求和对账。
3. 检查极值、负值、零值和突变点是否符合业务含义。
4. 比率同时保留分子与分母；分母为零时返回空值，不返回无穷或伪造的 0%。
5. 同比、环比必须使用可比周期，并说明缺失周期。
6. 结论附带指标、时间范围和对比基准；相关性不写成因果关系。

## 图表映射

| 问题 | 首选表达 |
|---|---|
| 平台、店群、店铺排名 | 降序横向条形图 |
| 日、周、月趋势 | 折线图，最多六条主序列 |
| 实际值与目标 | 子弹图、进度条或带目标线的柱图 |
| 金额与增长率 | 柱线组合图，明确双轴单位 |
| 状态构成 | 环形图；类别过多时改条形图 |
| 异常时间点 | 带形状标记和文字注释的折线图 |
| 精确明细与大量类别 | 可排序表格 |

图表服务于结论，不按模板空位倒推指标。
