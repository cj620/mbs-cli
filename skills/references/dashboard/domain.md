# 跨境电商铺货领域模型

## 核心对象

| 术语 | 定义 | 常见分析维度 |
|---|---|---|
| 平台 | Amazon、eBay、Shopee 等销售渠道 | 平台、业务模式 |
| 站点 | 平台下的国家或区域市场 | 国家、币种、时区 |
| 店铺 | 具体销售账号 | 平台、站点、负责人、状态 |
| 店群 | 按组织、负责人或经营策略管理的一组店铺 | 团队、负责人、策略 |
| SPU | 可聚合多个规格的商品主体 | 品类、开发人、生命周期 |
| SKU | 可库存、采购和销售的具体规格 | 仓库、成本、库存状态 |
| Listing | SPU/SKU 在具体平台店铺上的刊登实例 | 平台、站点、店铺、刊登状态 |
| 铺货 | 将商品批量分发并刊登到多个平台、站点和店铺的过程 | 成功率、耗时、覆盖率、失败原因 |

## 分析边界

- 不把 SPU、SKU 和 Listing 混为同一粒度；汇总前明确去重键。
- 店群不是平台账号的同义词；必须说明店群的组织或策略口径。
- 金额跨站点汇总前确认币种和汇率口径。
- 日界线跨站点比较前确认业务时区。
- 刊登量描述过程，在线 Listing 描述结果，两者不能替代。
- 销量、订单量、销售额、GMV 和利润使用各自明确口径。

## 常见问题

- 哪个平台或店群贡献最高，增长来自哪里？
- 哪些店铺的铺货成功率、在线率或转化表现异常？
- SPU 到 Listing 的覆盖率和生命周期分布如何？
- 失败刊登集中在哪些平台、站点、类目或错误原因？
- 库存、销量、毛利和 Listing 状态之间是否存在结构性问题？
