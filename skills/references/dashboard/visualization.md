# 看板可视化规则

## 使用模板

将 `assets/commerce-dashboard/` 整体复制到用户指定目录。保留模板源不变，在副本中修改 `data.js`、标题、模块和加载逻辑。

模板继承第 011 套源码的三栏结构：

- 左栏：排名和贡献结构；
- 中栏：核心指标、主趋势和异常趋势；
- 右栏：平台对比、异常明细和状态构成。

这只是默认骨架。业务问题不需要某一区域时删除，不使用无意义的占位图。

## 三种交付模式

### 数据分析结果

不复制模板。提供简洁的指标、图表或表格、结论、数据质量和口径说明。

### 一次性专题分析页

- 使用 `data.js` 的静态快照；
- 明确分析时间范围和生成时间；
- 允许删除筛选器和自动刷新；
- 页面应可由本地静态服务打开。

### 长期固定看板

- 实现 `window.loadMbsDashboardData(filters)`；
- 通过本机 `mbs serve` 读取稳定的只读接口；
- 提供筛选、刷新、加载、空数据、错误恢复和数据更新时间；
- 固定指标口径与返回契约，避免页面自行猜字段。

## 视觉与可用性

- 延续深蓝背景、青色数据系列和琥珀色重点，但保证正文对比度。
- 每屏只突出一个主指标，其他指标降低视觉层级。
- 排名、异常和状态同时显示文本值，不依赖悬浮或颜色。
- 桌面大屏优先，同时在 1440、1024、768 和 375 像素宽度下保持可读。
- 键盘焦点清晰；错误使用 `role="alert"`；动态图表提供文字摘要。
- 动画只用于状态变化，并遵循 `prefers-reduced-motion`。

## 数据文件

`data.js` 导出 `window.MBS_DASHBOARD_DATA` 示例。生成页面时替换其中数据，但保持字段结构；不要把 Cookie、token、完整 SQL 或敏感原始明细写入页面。
