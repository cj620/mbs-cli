## 当前强制约束

- 不把 `1.0.0` 合回 master，也不默认把 master 合入 `1.0.0`。
- 公共修复只能经独立评估后选择性迁移并执行完整验证。
- Git 分支存在不能证明 npm 已发布；没有标签、npm 和安装验证证据时必须保持“未发布”。
- 删除旧远程分支、创建标签、发布 npm 和修改 dist-tag 需要独立明确授权。
