## 当前强制约束

- 不把 `1.0.0` 合回 master，也不默认把 master 合入 `1.0.0`。
- 公共修复只能经独立评估后选择性迁移并执行完整验证。
- Git 分支存在不能证明 npm 已发布；每个维护版本仍必须具备标签、Actions、npm dist-tag 和安装验证证据。
- 删除旧远程分支、创建后续标签、发布后续 npm 版本和修改 dist-tag 需要新的明确授权。
- `latest` 属于 master 普通发布线；维护发布始终显式使用 `--tag maintenance-1`，不得移动 `latest`。
- 维护用户通过 `@maintenance-1` 安装升级，不使用固定跟随 `latest` 的 `mbs update`。

## 深入读取条件

- 发布或回滚 `1.x` npm 包。
- 修改分支命名、合并策略、CI、标签或自动更新通道。
- 从 master 迁移修复，或尝试重新合并两条代码线。
