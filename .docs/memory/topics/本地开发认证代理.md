## 当前事实

- 线上 CLI 只使用保存的登录 key、Cookie 缓存及其刷新流程，并从配置的 API 根地址进入各命令的正式服务路由；二维码和密码登录分别直达 `/eshop/manager/login.jsp` 与 `/eshop/manager/loginit2.jsp`，共享业务命令默认使用 `/gateway/cli`，语义召回例外使用 `/cli/gateway/cli-service`。
- `apiUrl` 表示服务器根地址；读取历史尾部 `/gateway` 配置时仅在内存中归一化，不自动改写用户文件。
- `devLoginUrl`、`MBS_DEV_LOGIN_URL`、`MBS_RECALL_BASE_URL`、`--cookie-prompt`、固定开发认证头和数据库开发代理入口均已删除。
- 新安装默认 API 地址为 `http://www.instudio.me:6206`；本机配置也已恢复为该地址，开发环境变量已清除。
- `find`、`describe`、数据库只读命令和正式的本地 `mbs serve` 能力保留。
- 4174 Vite 联调进程已停止；未读取或修改前端 Cookie 配置。

## 历史说明

- `20260810-[FEATURE]本地开发认证代理联调` 曾验证 4174 服务端 Cookie 代理方案可行，但该方案仅用于本地测试，已被本次任务完整替代。
- 历史 E2E 仅用于证明当时联调链路，不代表当前 CLI 仍提供该入口。

## 当前强制约束

- 不得把本地代理、Cookie 参数或隐藏环境变量重新带入线上构建。
- 需要本地认证联调时必须建立新的显式需求和安全审计，不能依赖历史入口。
- 不读取、保存、记录或输出用户提供的 Cookie。
