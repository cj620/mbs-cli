# 接口请求体编码

## 记忆元信息

- **记忆键**：`API-REQUEST-BODY-ENCODING`
- **负责模块**：`packages/shared`、`packages/cli`、manifest 生成与 Skill
- **当前状态**：已随 npm maintenance-1 1.0.4 发布并核验
- **最后核验时间**：2026-08-25
- **最后核验基线**：`689e82e` / `maintenance-1-v1.0.4` / npm 官方源核验
- **权威来源**：`20260825-[RELEASE]发布1.0.4维护版本`

## 当前事实

- npm `maintenance-1=1.0.4` 的 `mbs request --api-id` 已支持非 JSON 动态编码；旧无 ID JSON 形式保持兼容。
- 目标契约由 cli-service 的 `requestBodyMode/requestMediaType/requestCharset` 和 body 字段级元数据提供，`form` 不是字段作用域。

## 已发布变更

- 动态 request 已使用 `--api-id` 读取详情并由统一编码器处理 NONE、JSON、urlencoded、multipart、TEXT、XML 和 BINARY；旧无 ID JSON 形式保持兼容。
- manifest 生成命令和 serve 已复用相同编码器；旧 JSON manifest 按兼容默认处理，serve 明确禁止运行时文件读取。
- 嵌套表单支持 FLAT/DOT/BRACKET/JSON_STRING；`explode=false` 将对象或带子节点数组编码为单个 JSON 字符串，将标量数组编码为逗号连接的单值。
- 运行时文件路径、正文、Cookie 和响应不进入元数据、日志、遥测或项目文档。
- 官方源隔离安装已核验版本、request 帮助、Skill 内容和已编译请求体编码模块；未发送真实业务请求。

## 深入读取条件

修改 request/describe、manifest 生成、文件限制、multipart、字符集、发布或回滚时，读取本主题任务及 `DEC-001`。
