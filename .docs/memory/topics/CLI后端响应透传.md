## 当前强制约束

- 透传只改变输出表达，不改只读 method、路径、网关、Cookie 和权限边界。
- 业务错误仍使用非零进程退出码，认证类仍自动刷新一次。
- 不在日志、任务文档或测试中保存真实 response body。

## 深入读取条件

- 发布、回滚、改变版本策略或处理下游 envelope 兼容时，必须读取当前任务的需求与执行计划。
- 将透传扩展到 `find`、`describe`、`serve` 或本地命令时，必须重新确认产品范围和安全边界。
