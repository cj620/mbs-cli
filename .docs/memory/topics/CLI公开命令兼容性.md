## 当前事实

- npm `@mb-it-org/cli@0.1.58` 是当前已核验的已发布基线，包含五个后续工作区已删除或重命名的业务命令。
- 当前工作区生成模块不提供这五个旧命令；依赖它们的用户脚本在升级到该工作区产物后会中断。

## 待生效变更

- `20260810-[BUG]恢复已发布CLI旧命令` 已使用不受 manifest 清理影响的人工兼容插件恢复五个命令，本地契约、构建和命令发现验证通过。
- 该变更处于待发布状态；发布前不改变 npm 用户的当前事实，真实目标网关可达性仍待验收。
- 本轮不恢复旧 `mbs serve --project-apis` 路由。

## 当前强制约束

- 兼容命令必须保留 `0.1.58` 的命令 ID、flags、方法、路径和请求字段，不得映射到语义相近但不同的接口。
- 兼容实现继续使用 `MBSCommand` 的认证、网关、输出和错误契约。
- 仅允许只读 GET 和查询类 POST。

## 深入读取条件

- 修改、删除、重命名五个兼容命令或恢复旧 serve 路由时。
- 当前 manifest 重新生成同名命令，需要消除重复插件命令时。
- 目标网关不再支持旧接口，需要迁移、替代或回滚时。
- 发布、灰度或回滚兼容版本时。
