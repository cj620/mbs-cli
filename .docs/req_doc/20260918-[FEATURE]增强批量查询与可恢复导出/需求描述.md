# 需求描述：增强批量查询与可恢复导出

> 安全提示：本文档不得写入凭据、真实用户数据、未脱敏日志、请求响应正文、生产数据库标识或其他敏感证据。

## 1. 背景

当前数据库 Skill 已约束只读 SQL、显式列和结果限制，`mbs export` 也已使用 ExcelJS 流式 writer，但大批量任务仍缺少统一的游标分页、持久化执行日志、可恢复断点和有界重试契约。任务遇到网络中断或进程退出时，调用方无法可靠判断应继续既有结果还是重新全量查询，容易浪费已经完成的批次，或者通过无界重试长期占用资源。

## 2. 业务边界

- SQL 中的中文、保留字或特殊字符表名/字段名必须按数据源方言引用：Doris/MySQL 使用反引号，PostgreSQL 使用双引号。
- 大批量查询优先使用稳定、唯一、有序的键集游标分页；数据库导出必须由调用方显式提供游标列和方言，CLI 不猜测唯一键或数据库类型。
- 大批量导出和分析优先由可重复执行的脚本分批拉取，成功批次先写入持久化中间文件，再流式生成最终 Excel。
- 长时间导出任务在第一次远端请求前创建独立任务日志、断点和中间结果文件，并通过 stderr 告知任务 ID 和各文件路径。
- 中断任务再次执行时，不得静默继续或静默全量重跑；CLI 要求调用方显式选择从断点继续或创建新任务重新全量查询。
- 所有重试必须有上限。默认首次失败后最多重试三次，并采用有上限、带抖动的指数退避；权限、参数、SQL、只读校验等确定性错误不得重试。
- Excel 使用流式 writer 从中间 NDJSON 文件生成，写入临时文件并在成功关闭后原子替换最终文件；异常时保留中间结果与断点。
- 日志记录阶段、批次、游标摘要、行数、耗时、重试和文件状态，但不得记录凭据、完整 SQL、原始响应或业务行数据。
- 本任务不执行真实 MBS 查询，不修改后端权限或 SQL 安检，不发布、不安装、不提交或推送。

## 3. 受影响范围

- `packages/export`：批次源接口、数据库键集分页、任务日志、断点、中间结果、有界重试、恢复选择和流式 Excel 收口。
- `skills/references/database/SKILL.md`：标识符引用、键集分页和大批量数据库脚本约束。
- `skills/references/export/SKILL.md`：日志、断点、恢复、重试、中间文件和 Excel 流式写入流程。
- `skills/references/dashboard/SKILL.md` 与 `analysis.md`：大批量分析脚本优先及任务日志约束。
- `scripts/lib/generated-skills.test.mjs`、`packages/export` 测试：公共行为回归。
- `.docs/req_doc` 与 `.docs/memory`：任务、决策和待生效事实。

## 4. 输入与输出

### 4.1 数据库游标分页输入

- 基础只读 SQL；
- 一个或多个稳定游标列；
- 批次大小；
- 数据库方言；
- 可选的恢复游标。

### 4.2 导出任务输出

- 最终 `.xlsx` 文件；
- 独立 NDJSON 执行日志；
- 原子更新的 JSON 断点文件；
- 分批持久化的 NDJSON 中间结果；
- stdout 最终摘要以及 stderr 初始化、进度、重试和恢复提示。

## 5. 验收标准

- 中文或特殊标识符按明确方言引用，未知方言不猜测。
- 数据库键集分页生成稳定 `ORDER BY`、游标谓词和有界 `LIMIT`，游标为空、缺列或不前进时安全失败。
- API 页码/游标分页和数据库键集分页均能在批次成功后保存下一恢复位置。
- `export run` 在请求前创建日志、断点和中间文件并输出位置。
- 存在未完成任务时，未指定 `--resume` 或 `--restart` 必须停止并给出两个明确命令。
- `--resume` 复用成功批次；`--restart` 创建新任务且不删除旧任务证据。
- 默认最多重试三次，指数退避有上限，无任何无限循环路径；确定性错误不重试。
- Excel 从中间文件流式生成，临时文件只有在 workbook 成功提交后才替换最终文件。
- 中断和失败保留日志、断点和中间结果，最终成功经过行数一致性校验。
- 新增或修改的人工维护函数具有同步文档；定向测试、全仓测试、构建和差异检查通过。
- 不覆盖当前工作区中参数依赖解析和明确数据库目标直达查询的既有修改。
