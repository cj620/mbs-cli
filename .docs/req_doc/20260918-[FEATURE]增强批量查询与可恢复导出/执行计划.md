## 3. 已确认决策、执行假设与约束

- `packages/export` 的外部 seam 保持 `plan → run`，复杂的批次、断点和文件生命周期收敛到内部深模块。
- `runSource` 兼容接口保留；新增批次接口供可恢复导出使用，避免把任务状态泄漏到每个调用方。
- 大批量数据库分页只在显式提供游标列时启用；CLI 不从 DDL 或列名猜测唯一键。
- 默认数据库方言仅适用于默认 Doris；外部数据源启用游标分页时必须显式声明方言。
- 不在未完成 XLSX 上原地续写；成功批次进入 NDJSON 中间文件，恢复后重新流式生成临时 XLSX。
- `--restart` 创建新任务并保留旧任务证据，不执行破坏性删除。
- 默认“重试三次”解释为首次失败后最多三次重试，总计最多四次尝试。
- HTTP 客户端已有认证失效单次刷新保持不变；本任务的批次重试只处理暂时性传输/限流/网关错误，不扩大认证重试。
- 现有后端响应透传、只读、安全和认证凭据边界保持不变。

### 3.1 规则冲突

无未解决冲突。Excel 中断续写要求与 XLSX 容器不可安全原地恢复之间，通过“持久化 NDJSON 中间结果，再流式重建临时 XLSX”解决。

## 8. 风险与回滚

- **数据一致性风险**：分页期间源数据变化可能导致遗漏或重复。控制：要求稳定唯一游标、固定筛选窗口、游标前进检查和最终行数校验。
- **SQL 方言风险**：错误引用符会导致 SQL 失败。控制：外部数据源显式声明方言，默认只推断无 host 的 Doris。
- **断点损坏风险**：进程中断可能留下半写状态。控制：临时文件写入后原子替换，批次数据持久化成功后才推进断点。
- **XLSX 损坏风险**：流式 workbook 中断时文件不完整。控制：写临时文件，成功提交后替换；恢复时从中间 NDJSON 重建。
- **日志泄露风险**：错误或参数可能带敏感值。控制：日志仅记录分类、状态、计数和脱敏摘要，不记录请求/响应正文。
- **重试放大风险**：确定性错误被重复执行。控制：白名单识别暂时性错误，严格最大次数和任务总状态。
- **回滚**：反向恢复本任务新增的 export 模块、flags、Skill 和文档差异；任务中间文件位于用户配置目录，测试只使用临时目录且不触碰真实任务文件。
