## 停止条件

- 出现无法确认归属的工作区修改、凭据片段、生产数据、占位实现或核心验证失败。
- `origin/1.0.0` 在基线之外前进，或目标标签/npm 精确版本已经存在。
- 分支 CI、Release workflow、npm dist-tag 或官方包验证任一失败。
- 任一步骤要求强推、删除远端标签、改写历史，或把 npm `latest` 移动到用户未明确授权的版本。
