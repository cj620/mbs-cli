## 已确认结论与决策

| 编号 | 类型 | 内容 | 证据/状态 |
| :--- | :--- | :--- | :--- |
| R-001 | 根因 | CLI 扫码打开旧商城 JSP，页面不会履行认证中心 Cookie 契约，导致轮询不结束 | 行为回归命中，已修复为认证中心入口 |
| R-002 | 根因 | HTTP 浏览器不能使用 `Secure` Refresh；旧页面还依赖安全上下文随机 API | 页面与 Cookie 回归命中；服务端 HTTP 扫码不再创建 Refresh，CLI 采用已验证的两小时 Session-only |
| R-003 | 排除 | 密码/LongToken 登录后的普通业务请求并未漏带认证材料 | Node loopback 实际请求证明首发含 `SESSION` 和 `client-type: cli`，长期凭据不进入业务请求 |
| R-004 | 根因 | 网关把认证中心 401 折成 403，阻断 CLI 既有的 401/601 唯一刷新 | 网关 Red→Green 测试与目标环境只读探针一致 |
| R-005 | 放大因素 | 网关负向权限缓存使用滑动续期，可能持续遮蔽身份或权限变化 | 改为只缓存固定十秒正向允许；历史 `0` 重查 |
| R-006 | 根因 | 认证拦截器在放行扫码页前创建匿名 Session，CLI HTTP 分支首次身份拒绝后立即结束 | CLI 忽略已拒绝候选并等待 Session 旋转；认证中心入口清理预登录 Session |
| D-001 | 决策 | 扫码只从认证中心入口完成，同一浏览器回调直接建立 Session；删除跨浏览器 trace→Session 转移，旧查询端点固定 410 | 有效 |
| D-002 | 决策 | HTTPS 仍要求唯一 Session/有效 Refresh；HTTP 仅允许唯一安全 Session、完全没有 Refresh且 current-user 验证成功的有界降级 | 有效 |
| D-003 | 决策 | 页面导航、Cookie 轮询与 current-user 共用绝对 deadline；支持底层请求的操作必须接收 `AbortSignal` | 有效 |
| D-004 | 决策 | 普通业务请求只携带 Session、`client-type: cli` 和刷新后内存 Bearer；Refresh/LongToken 永不进入业务请求，Access 不持久化 | 有效 |
| C-001 | 约束 | HTTP 是用户既有临时兼容，不描述为安全；外部 HTTPS 可用后必须迁移 | 有效 |
| C-002 | 约束 | 不修改旧商城原生 `JSESSIONID`、RBAC 业务规则、数据库或生产配置 | 有效 |

## 诊断反馈环

1. 既有 CLI/shared 定向测试最初全部通过，证明原测试没有覆盖用户精确症状。
2. 新增扫码行为回归，先稳定暴露旧入口、HTTP 双 Cookie 永远无法满足、Cookie 作用域、总 deadline 和失败未快速收口，再修改实现转绿。
3. 新增 Node loopback 实际 HTTP 回归，捕获首发请求头与 401 后唯一重试，排除“CLI 没带 token/session”。
4. 新增网关单元回归，修复前认证中心 401 被转为 `false/403`，修复后保留 HTTP/body 401；真实 RBAC `false` 仍为 403。
5. 新增认证中心 MockMvc/服务测试，覆盖可打包扫码页、服务端 state、回调 Cookie、Session/Refresh、旧 trace tombstone、异常状态和敏感请求日志。
6. 对目标网关只使用人工无效凭据和不存在的合成服务路径做只读探针：无效 Session/Bearer 仍返回 403，不带 CLI 标识仍走旧逻辑，证明目标运行态尚未包含当前修复或仍被旧配置覆盖；该探针不能代替真实身份联调。

## 回滚、发布与观察

- 回滚按模块恢复本任务文件并重跑对应 Red 反馈环；不得恢复旧 trace 会话领取、客户端旧密钥或网关 401→403 行为。
- 本地修复不等同于发布。目标环境必须同步发布 CLI、认证中心和网关，并核对 Nacos 白名单、共享 Redis/Session namespace、Cookie 域与 TLS 转发头信任配置。
- 若 TLS 在反向代理终止，必须由可信代理/容器配置让 Servlet 正确识别外部 HTTPS；否则服务端会按 HTTP 跳过 Refresh，CLI 的 HTTPS 安全分支会拒绝 Session-only。
- 发布后只记录脱敏指标：扫码成功/超时、页面 5xx、compat-session 成功率、业务 401/601、唯一重试成功率及 RBAC 401/403 分类；不得包含用户或凭据。
- HTTP Session-only 最长两小时、不可刷新且明文传输；网关正向权限缓存可能产生最长十秒 stale allow，均为已知剩余风险。
