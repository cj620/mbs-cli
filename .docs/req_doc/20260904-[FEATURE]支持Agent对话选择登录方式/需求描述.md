# 需求描述：支持 Agent 对话选择登录方式

> 安全提示：本文不得记录真实账号、密码、LongToken、Cookie、Session ID、请求响应正文或生产内部地址。

## 任务属性

- 级别：L3（认证交互、公共 CLI 契约与跨进程资源变化）
- 类型：FEATURE / SECURITY
- 任务状态：已完成
- 执行授权：已授权
- 授权来源：用户先要求“开始修改代码”，后明确要求提交全部未提交代码并发布 `1.1.0`
- 交付状态：已随 npm `1.1.0` 发布
- 记忆键：`AUTH-CREDENTIAL-BOUNDARY`

## 背景

Agent 的命令执行通道通常重定向 stdin/stdout。裸 `mbs login` 当前直接启动 Inquirer 终端菜单，无法接收方向键和回车，最终出现 `ExitPromptError`。用户要求不通过 MCP 收集登录交互，而是在 Agent 对话中先选择登录方式：扫码模式由 CLI 打开浏览器；账号密码和管理型 `LongToken` 模式由 CLI 自动打开可见交互终端，让秘密只在该终端中输入。

本任务补充 `20260903-[FEATURE]接入长短Token刷新登录`，不改变 `MBS_KEY` 禁令、长期凭据互斥缓存、短期 Access Token 仅内存或登录前清理规则。

## 业务与安全边界

本任务包含：

1. 为 `mbs login` 增加显式扫码和管理型 Token 模式参数；保留既有 `--password` 和人工终端中的三选一菜单。
2. 非交互调用未指定登录方式时，不启动 Inquirer，而是返回稳定、安全且可操作的错误，提示 Agent 先在对话中询问并调用明确模式。
3. 非交互调用账号密码或管理型 Token 模式时，在 Windows 上自动启动新的可见交互终端；父进程只传递登录模式、Node 入口和工作目录，不传递任何账号、密码或 Token。
4. 扫码显式模式可在非交互 Agent 通道中直接启动现有浏览器认证流程。
5. 更新随 CLI 发布的 MBS Skill，使 Codex、Claude 等 Agent 在认证失效或用户要求登录时先通过对话询问方式，再调用确定性命令。
6. 子终端结束后父命令传播退出状态；成功时输出既有安全成功结构，失败不得伪装成功。

本任务不包含：

- 使用 MCP Elicitation、MCP App 或其他 MCP 交互界面收集登录方式或凭据；
- 通过聊天、命令参数、环境变量、stdin 管道、stdout、日志或遥测传递账号密码和管理型 `LongToken`；
- 改造认证中心、网关、Cookie/Refresh 协议或凭据缓存格式；
- 自动访问真实账号或生产认证环境；
- macOS/Linux 图形终端启动适配；不支持的平台必须安全失败并提示使用本机交互终端；
- 本功能实施任务本身不包含 Git 暂存、提交、推送或发布；这些动作后来由独立的 `20260904-[RELEASE]发布1.1.0维护版本` 任务获得用户明确授权并统一执行。

## 输入与输出

- `mbs login`：仅在当前 stdin/stdout 均为交互式终端时显示原三选一菜单；非交互环境返回选择提示。
- `mbs login --qr`：跳过菜单并直接启动扫码浏览器。
- `mbs login --password`：交互终端内直接隐藏输入；非交互 Windows 环境自动打开可见终端完成输入。
- `mbs login --managed-token`：交互终端内直接隐藏输入；非交互 Windows 环境自动打开可见终端完成输入。
- 三个模式参数互斥；内部子进程防递归参数不出现在普通帮助中。
- 登录成功继续输出 `{ "ok": true, "data": { "message": "Authenticated successfully" } }`；失败保持非零退出码和安全错误结构。

## 验收标准

1. 非交互裸登录不再进入 Inquirer，也不再出现 `ExitPromptError`，错误提示包含三个明确命令。
2. `--qr` 在非交互环境直接复用浏览器扫码流程，且登录缓存清理早于浏览器启动。
3. `--password` 与 `--managed-token` 在非交互 Windows 环境只启动对应的可见子终端；父进程和启动参数不包含秘密。
4. 子终端再次进入 CLI 后先清空认证缓存，再收集账号密码或 Token；防递归参数避免重复拉起终端。
5. 交互终端中的裸菜单及已有 `--password` 行为保持兼容；三个公开模式参数互斥。
6. 终端启动失败、平台不支持、子进程认证失败和取消均失败关闭，不恢复旧认证态、不输出凭据或底层敏感对象。
7. MBS Skill 明确 Agent 对话消歧流程和三条确定性命令；密码与 Token 必须在新终端输入。
8. 定向测试、受影响包测试、全仓测试、构建、CLI help、非交互协议 smoke、敏感信息检查与差异检查通过。
