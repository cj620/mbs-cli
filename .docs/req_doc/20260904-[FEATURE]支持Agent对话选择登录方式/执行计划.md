## 执行前提与专项记录

- 受保护资产：账号密码、管理型 `LongToken`、Refresh Cookie、SESSION、短期 Access Token 和用户身份。
- 不可信输入：CLI flags、TTY 状态、子进程退出码、配置 URL 和认证响应。
- 资源所有权：父命令拥有终端启动进程并等待退出；扫码命令继续拥有并关闭浏览器；子命令拥有自己的终端 prompt。
- 依赖：优先使用 Node 标准库和系统 PowerShell，不新增第三方依赖；PowerShell 启动参数固定且不拼接用户输入。
- Git：本功能实施阶段原仅允许读取状态和修改范围文件；用户后续已通过独立 1.1.0 发布任务授权暂存、提交和普通推送全部当前改动。
- 回滚：逐文件移除新增 flags、终端模块和 Skill 规则即可恢复历史交互；不得恢复任何 `MBS_KEY` 方案。登录开始已清除的旧凭据不可通过代码回滚恢复。
- 上线观察：后续发布后观察非交互登录错误率、终端启动失败率、子命令退出码和用户取消率；日志不得包含凭据或完整环境。

## 风险与回滚

- Windows 图形终端由系统 PowerShell `Start-Process` 提供；系统策略禁用 PowerShell 或图形会话不可用时必须返回安全错误。
- 可见子终端属于独立进程，用户取消、关闭窗口或认证失败必须通过退出码传播，父进程不得假报成功。
- Agent 是否显示按钮由宿主决定；共享 Skill 只能保证语义流程，不能保证统一控件样式。文字询问是兼容降级。
- 非交互登录开始仍会清除旧认证态；终端启动失败后需要重新登录，这是现有安全规则的预期结果。
- 回滚触发：CLI 无法构建、终端启动协议不稳定、秘密出现在参数/输出或历史交互回归。回滚只移除本任务差异并复验旧命令，不能恢复已清理凭据。
