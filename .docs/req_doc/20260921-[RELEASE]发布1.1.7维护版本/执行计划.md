## 风险与回滚

- 发布前失败不创建标签；发布后发现问题不得覆盖版本，只能提升新补丁或回退 dist-tag。
- `latest` 提升前的回滚锚点固定为已核验的 `1.1.6`。
- 临时发布辅助 workflow 如有创建，必须固定包名/版本、有限重试、成功后删除并提交，不能保留泛化发布入口。
- 真实后端链路仍未验证；官方包合成 HTTP 错误回归用于证明安装产物包含修复。
