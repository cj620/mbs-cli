## 风险与回滚

- 风险：共享 LongToken 交换函数同时服务首次登录和 Refresh，直接全局删除请求头会扩大影响。
- 控制：调用方显式声明登录或 Refresh 场景，并用测试分别锁定。
- 回滚：恢复本任务对共享认证模块和测试的局部差异；不会触碰凭据缓存或并行任务文件。
