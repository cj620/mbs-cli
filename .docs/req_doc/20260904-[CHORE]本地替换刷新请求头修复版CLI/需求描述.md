## 目标与范围

本任务包含：

1. 确认工作区构建产物包含兼容会话交换接口请求头修复。
2. 使用 npm 本地链接，将本机当前活动的 `mbs` 全局包切换到 `D:\workspace\mbs-cli\packages\cli`。
3. 验证命令解析路径、链接目标、版本输出、`refresh --help` 和内置 Skill。
4. 记录可执行的回滚方式和本机交付事实。

本任务不包含：

- 发起真实 login、refresh、whoami 或业务 API 请求；

- 修改被 PATH 遮蔽的用户级 npm 副本；
- 修改版本号、依赖、注册表、npm dist-tag 或正式发布包；
- Git 暂存、提交、推送、标签、发布或远程写入。

## 验收标准

1. 系统级全局包路径成为指向工作区 `packages/cli` 的链接。
2. `Get-Command mbs` 仍解析到系统级 npm shim，且该 shim 最终使用工作区代码。
3. `mbs --version`、`mbs refresh --help` 和内置 Skill 读取成功。
4. 工作区编译后的兼容会话交换实现不组装 `client-type`；普通业务请求头保持不变。
5. 不发送真实认证请求，不读取或输出任何凭据。
6. 回滚可通过重新安装官方 `@mb-it-org/cli@1.1.1` 完成。

## 风险与回滚

- 风险：工作区后续重新构建或修改会立即影响本机活动命令，因为全局入口使用本地链接。
- 风险：删除或移动工作区会使本机活动命令失效。
- 回滚命令：`npm install -g @mb-it-org/cli@1.1.1 --registry=https://registry.npmjs.org/`。
- 回滚仅恢复官方安装目录，不改动认证缓存和仓库文件。
