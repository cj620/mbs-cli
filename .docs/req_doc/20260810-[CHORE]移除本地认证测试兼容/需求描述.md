# 需求描述：移除本地认证测试兼容

> 安全提示：本文不得记录 Cookie、Session ID、账号密码、真实用户数据、未脱敏请求响应或其他敏感证据。

## 背景

本地联调已经完成。此前为本地测试增加的 4174 登录代理、一次性 Cookie 提示、本地召回地址覆盖和 9090 默认地址不应进入线上标准构建。

## 目标

1. 删除 `devLoginUrl`、`MBS_DEV_LOGIN_URL`、`MBS_RECALL_BASE_URL`、`--cookie-prompt` 及固定开发认证头等本地认证兼容。
2. 恢复默认线上 API 地址和保存登录态驱动的统一认证流程。
3. 保留正式的 `find`、`describe`、数据库只读查询、`serve`、请求取消与流式查询能力。
4. 清理本机持久化开发登录地址和相关环境变量，不读取、复制或输出 Cookie。

## 安全边界

- 不读取或修改前端 Cookie 配置，不把既有凭据写入代码、测试、文档或命令输出。
- 不修改 `pms-front` 文件，不触碰业务数据，不执行写业务接口。
- 不覆盖、暂存、提交或推送工作区中无法确认归属的其他修改。

## 验收标准

1. CLI 帮助、源码、测试和 Skill 中不再存在上述本地认证入口。
2. 新安装默认地址恢复为 `http://www.instudio.me:6206`，现有本机配置同步恢复且不保留 `devLoginUrl`。
3. `find`、`describe` 和数据库命令仍使用普通已保存登录态及 `/gateway/cli` 路径。
4. 定向测试、全量测试和构建通过；本地全局 link 与 Codex Skill 指向清理后的产物。
