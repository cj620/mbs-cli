# 需求描述：统一语义发现与数据库表召回（mbs-cli）

## 0. 任务定位

本任务是 `cli-service` 同名 L3 需求的 CLI 消费侧。后端需求、领域词汇和架构决策为权威来源；本仓库负责让智能体以一个自然语言入口安全消费 workflow/api/table 混合候选，并衔接既有只读执行命令。

本任务继承 `20260722-[FEATURE]接口检索降噪与智能召回` 的远程唯一发现、薄 Skill 和无本地接口卡片原则，不恢复 manifest、接口 Markdown 或本地词法降级。

## 1. 用户体验

用户只表达业务目标，例如：

```text
查询上个月每个店铺退款金额
```

智能体直接执行：

```text
mbs find "查询上个月每个店铺退款金额"
```

不得要求用户先回答“查接口还是查表”。`--target-type` 只允许作为系统内部、高级诊断或 workflow 子步骤收窄能力，主 Skill 不向最终用户暴露为前置选择。

## 2. 混合候选

`mbs find` 接受后端返回的 workflow/api/table 候选，并保持统一输出 envelope。公共字段包括类型、稳定身份、名称、描述、分数、匹配理由和结构化下一步动作。

- workflow：读取步骤，用每个子意图再次执行统一 find。
- api：执行 `mbs describe <apiId>`，再用业务命令 `--help` 校验参数并执行。
- table：执行现有 `mbs database show-create-table` 获取权威结构，再生成并执行受控 `mbs database query`。

CLI 不负责重新计算跨类型排序，也不使用本地目录补候选；后端失败或契约无效时明确失败。

## 3. table 候选契约

table 候选至少包含：

- 经过后端校验的稳定目标键。
- 数据源别名、database、schema 和 table。
- 表业务名称、用途与数据粒度摘要。
- 可选的主要维度、指标和时间字段摘要。
- 结构化详情动作，而不是可直接交给 shell 的整段命令字符串。

数据库标识不能复用 API 命令名称的小写短横线规则；CLI 应分别校验长度、控制字符和空值，并通过 oclif 参数调用或结构化参数渲染，禁止 shell 拼接。

## 4. 执行安全

- CLI 只消费后端已经权限过滤的 table 候选，但不能把候选当作授权证明。
- `show-create-table` 和 `query` 必须继续走后端二次鉴权、数据源路由、SQL 安检和权限改写。
- 不在本地日志、遥测或错误中记录自然语言原文、Cookie、完整 DDL、SQL 返回行或未授权候选。
- table 详情和查询不得自动执行；智能体必须先读取结构并构造 SELECT，只读边界不变。
- 后端提供的任意命令文本、SQL 或路径都视为不可信输入。

## 5. Skill 行为

主 Skill 流程更新为：

1. 对用户原始业务目标执行 `mbs find`，不询问目标类型。
2. 同时评估 workflow/api/table 候选的匹配理由、时效、口径和执行成本。
3. workflow 命中时按步骤继续 find；api 命中时 describe；table 命中时 show-create-table。
4. 候选接近且口径可能不同时，向用户提出业务澄清，不静默任选。
5. 最终执行仍遵循现有只读命令和数据库安全规则。

域级 Skill 仍只承担业务域导航，不生成或内置表卡片、接口卡片、DDL 或端点 Markdown。

## 6. 兼容与版本能力

- 后端在 CLI 支持 table 类型前不得向旧客户端返回 table 候选。
- CLI 遇到未知候选类型必须以契约错误失败，不得忽略后继续执行可能错误的候选。
- 现有 `api`、`workflow` 输出继续兼容；table 支持随明确版本发布。
- 全局安装、Codex Skill 安装和后端能力需通过版本或能力协商同步灰度。

## 7. 验收标准

- `mbs find` 仅凭自然语言可解析 workflow/api/table 混合响应。
- table 候选能生成结构化 `show-create-table` 参数并衔接现有命令，不执行 shell 拼接。
- 未知类型、缺失数据源、非法数据库标识、超长字段和契约污染均稳定失败。
- table 候选不会进入本地遥测原文、错误正文或生成 Skill。
- API/workflow 现有测试、数据库命令测试、生成器测试和全量构建无回归。
- 真实验收覆盖 API 路径、table 路径、workflow 路径、跨类型歧义、无权限表和后端不可用。
