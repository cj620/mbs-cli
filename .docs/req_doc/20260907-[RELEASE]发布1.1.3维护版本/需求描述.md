# 需求描述：发布 1.1.3 维护版本

> 安全提示：本文不得记录账号、密码、Cookie、Token、Session ID、真实请求正文、生产响应、签名地址或未脱敏发布日志。

## 任务属性

- 级别：L3（认证行为、Git 远程写入和 npm 生产发布）
- 类型：RELEASE / SECURITY
- 任务状态：已完成
- 执行授权：已授权
- 授权来源：用户明确要求“提交代码并发布1.1.3版本”
- 交付状态：已发布
- 关联修复：`20260904-[BUG]修复登录完成与请求认证`

## 背景

`1.0.0` 长期维护分支当前已发布 npm `maintenance-1=1.1.2`。当前工作区完成了 CLI 范围内的扫码登录闭环修复：迁移到认证中心入口，增加 URL 和 Cookie 边界、绝对超时取消、HTTP 匿名 Session 继续等待与经验证的两小时 Session-only 降级。本地 V3 记录已通过，用户要求提交当前修复并发布 `1.1.3`。

## 目标

1. 审查并提交当前工作区中属于 CLI 登录与请求认证修复的代码、测试、Skill、规范、决策和审计文档。
2. 将 `@mb-it-org/cli` 从 `1.1.2` 升级到未占用的 `1.1.3`。
3. 普通推送到 `origin/1.0.0`，并在每个发布关键点确认分支 CI 成功。
4. 创建并推送 `maintenance-1-v1.1.3`，由既有 Release 工作流发布 npm `maintenance-1`。
5. 发布后核验精确版本、dist-tag、官方源安装包和 Skill；保持 npm `latest=0.1.59` 不变。

## 发布内容

- 扫码登录改用认证中心入口，在打开浏览器前校验 HTTP(S) URL，且只读取实际登录 origin 可见 Cookie。
- 导航、Cookie 轮询与 current-user 验证共享绝对截止时间，支持底层 `AbortSignal` 取消，成功和失败路径均正确关闭浏览器。
- HTTPS 扫码仍强制唯一有效 `SESSION + AUTH_REFRESH`；HTTP 仅接受 current-user 验证后的唯一 `SESSION`，并限定两小时且不可自动刷新。
- 扫码前匿名 Session 被身份校验拒绝后继续等待回调旋转的新 Session，不提前关闭页面。
- 密码、管理型 `LongToken`、compat-session、普通业务请求的长期凭据与短期 Access 边界保持不变。

## 范围与安全边界

- 目标仅为当前 `mbs-cli` 仓库的 `origin/1.0.0`、标签 `maintenance-1-v1.1.3` 和 npm `maintenance-1`。
- 本任务不提交、推送或部署 `technical-center`；该仓库的认证中心和网关修复仍需独立授权与交付。
- 不修改或推送 `master`，不创建 `v1.1.3`，不移动 npm `latest`。
- 不强推、不删除远程引用、不改写已推送历史、不覆盖或删除已发布 npm 版本。
- 不读取、重放、记录或提交任何真实凭据；真实登录不作为发布自动化输入。
- 发布失败时停在可恢复状态；npm 版本不可覆盖，已发布缺陷通过更高补丁版本前向修复。

## 输入与输出

- 输入：当前已完成本地 V3 的 CLI 认证修复工作区、版本 `1.1.3` 和既有维护发布工作流。
- 输出：功能提交与版本提交进入 `origin/1.0.0`，npm 官方源发布 `@mb-it-org/cli@1.1.3` 并将 `maintenance-1` 指向该版本。

## 验收标准

1. 待提交差异完整且只包含当前 CLI 认证修复、关联审计、版本和发布审计，不含真实凭据、占位实现或无关产物。
2. frozen install、定向测试、全仓测试与构建、发布保护、CLI/Skill 冒烟、差异和敏感信息检查通过。
3. 功能提交和版本提交均普通推送到 `origin/1.0.0`，对应分支 CI 成功。
4. 维护标签精确指向版本提交，Release 工作流成功发布 npm。
5. npm 官方源存在 `1.1.3`，`maintenance-1=1.1.3`，`latest=0.1.59`。
6. 官方源隔离安装验证版本、login/refresh 帮助、主 Skill 和 global Skill，然后回填任务、认证记忆与维护线记忆。

## 回滚与观察

- 标签推送前通过普通修复提交纠正问题，禁止改写已推送历史。
- npm 发布后不能覆盖同版本；严重缺陷使用更高补丁版本，dist-tag 回调需要新的明确授权。
- 观察分支 CI、Release 作业、npm 精确版本、dist-tags 和官方源隔离安装结果。
