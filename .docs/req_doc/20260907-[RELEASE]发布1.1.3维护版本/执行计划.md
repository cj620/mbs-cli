## 执行前提与安全专项

- 受保护资产：npm 发布权限、GitHub 维护分支与标签、认证凭据、发布制品完整性。
- 不可信输入：远端分支状态、npm registry 查询、CI/Release 状态；发布前逐项校验，不根据单次缓存结果推断成功。

- 失败行为：任一前置验证或 CI 失败即停止后续不可逆步骤；不重试掩盖失败，不强推。
- 凭据处理：本地推送命令不显式携带 npm Token；仅 GitHub Actions 使用仓库 Secret。
- 回滚：标签前使用普通修复提交；npm 发布后只允许更高版本前向修复。
