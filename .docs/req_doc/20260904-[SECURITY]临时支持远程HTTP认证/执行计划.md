## 风险与回滚

- 风险：远程 HTTP 会明文传输认证凭据，且配置错误的 HTTP 目标会直接收到凭据。
- 控制：继续严格校验 URL 结构、不记录凭据、不改变安全存储边界，并在用户文档中醒目标明风险。
- 回滚：恢复 HTTPS/loopback 门禁即可，不需要迁移认证缓存；如服务端提供 HTTPS，重新运行 `mbs config init` 配置 HTTPS 地址。
