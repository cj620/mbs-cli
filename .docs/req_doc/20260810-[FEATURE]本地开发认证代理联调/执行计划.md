## 5. 风险、保护与回滚

- 受保护资产：Cookie、用户身份、后端只读数据权限、本机代理边界。
- 不可信输入：环境变量 URL、代理响应、召回候选和数据库元数据。
- 失败行为：配置非法、代理不可达或认证失败时停止，不回退匿名、普通缓存或其他地址。
- 回滚：执行 `mbs config set-dev-login --clear` 并删除可能存在的 `MBS_DEV_LOGIN_URL` 即恢复普通认证；代码回滚只移除代理适配，不触碰 Cookie 或前端配置。
- 上线观察：本地仅观察结构化认证分类、连接失败和命令退出码；不记录 URL、Cookie 或响应正文。
