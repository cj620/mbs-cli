## 风险与回滚

- **兼容风险**：异步读取 rejection body 可能影响普通 HTTP 错误；通过普通对象 rejection 回归与全仓测试控制。
- **资源风险**：错误流未关闭会占用 Socket；正常、超限和解析失败路径都必须结束或销毁流。
- **安全风险**：不记录响应正文；测试只使用合成内容；错误体读取有界。
- **代码回滚**：普通反向恢复当前任务差异并重跑原红灯测试。
- **本机回滚**：必要时显式安装已核验的旧版本；npm 已发布版本不覆盖。
