## 风险、数据保护、回滚与观察

| 风险 | 控制 | 回滚/处置 |
| :--- | :--- | :--- |
| 下游脚本仍解析 `ok/data/error` | 文档明确 breaking contract，测试固定新 stdout | 发布前确认版本和迁移通知；需回滚时普通反向提交本任务差异 |
| 后端错误 body 含内部细节 | CLI 只向已认证本地调用者输出；不记日志、不写审计正文；信任后端对客户响应做安全裁剪 | 若发现敏感错误体，停止发布并由后端修正对客户契约 |
| 业务错误被当成进程成功 | 继续根据现有业务代码分类并使用非零退出码 | 定向测试覆盖未知 code、权限和认证失败 |
| 认证过期无法自动恢复 | 携带原始 body 时仍使用 `NotAuthenticatedError` 驱动一次刷新 | 测试首次失败、刷新成功和第二次失败 |

- **受保护资产**：Cookie、登录态、后端业务响应与下游脚本契约。
- **不可信输入**：所有后端 response body 保持 `unknown`，不作内部安全决策。
- **失败行为**：有后端 body 时输出最后一次 body；无 body 时输出安全本地错误；不伪成成功。
- **上线前验证**：必须另行完成版本策略、下游迁移通知、打包安装和目标网关人工样本验收。
- **上线后观察**：命令非零退出率、认证刷新成功率、后端错误 code 分布和下游解析失败；不记录 response body。
- **回滚入口**：在未发布前恢复本任务文件差异；发布后通过普通反向提交恢复 envelope 和错误转换，无数据迁移。
