## 风险、数据保护与回滚

- **磁盘泄露面扩大**：Access Token 从内存扩展到受保护缓存。缓解：短期有效、字段严格校验、文件权限保持仅当前用户、禁止任何输出和复制。
- **陈旧 Bearer**：本地时间漂移或服务端提前撤销可能使未到期 Token 被拒绝。缓解：401/601 唯一刷新；最终错误原样传播，不隐式清缓存。
- **多进程竞态**：登录型 Refresh 轮换仍可能被并发进程同时使用。该风险既有，本任务不引入无证据的锁；若回归表明扩大影响，停止并单独设计。
- **403 误分类**：本任务不把所有 403 当认证失败，避免真实权限拒绝导致长期凭据滥用和无意义重试。
- **旧版本兼容**：新增缓存字段为可选；旧版本会忽略额外字段。回滚代码后可继续读取既有长期凭据，但不会使用已保存 Access。
- **回滚方法**：仅恢复本任务代码和文档差异并重跑原认证回归；不得删除用户缓存、恢复 `MBS_KEY` 方案或覆盖其他任务修改。
- **上线前验证**：V3 本地自动化、构建、敏感扫描、缓存兼容和实际 HTTP loopback 必须完成。
- **上线后观察**：使用脱敏聚合指标观察 compat-session 成功率、401/601 次数、唯一重试成功率、最终 401/403 比例和缓存解析失败；不得记录身份或凭据。
