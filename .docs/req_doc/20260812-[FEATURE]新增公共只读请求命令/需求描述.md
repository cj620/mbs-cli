# 新增公共只读请求命令

> 安全提示：本文档禁止写入 Cookie、登录密钥、真实用户数据、未脱敏请求响应和其他敏感生产证据。

## 背景

后端接口会持续新增，不能要求每个接口先生成并发布专用 CLI 命令。现有 `mbs find → mbs describe` 已能动态定位查询接口并返回 `method`、`path` 和参数定义，但公开链路在缺少预生成 `command` 时停止，无法继续调用已获授权的新接口。

所有普通业务接口统一经过：

```text
<apiRoot>/gateway/cli/<接口路径>
```

网关继续负责身份和权限控制，因此不需要为动态执行另增 `cli-service` 接口。

## 业务边界

- 新增公开 `mbs request <GET|POST> <path>` 命令，复用保存的 Cookie、自动刷新、统一成功/失败输出和共享 `/gateway/cli` 前缀。
- `path` 只接受以单个 `/` 开头的相对接口路径，禁止绝对 URL、协议相对地址、反斜杠、控制字符、查询串、片段、未替换路径占位符和路径穿越。
- 仅允许 `GET` 与查询类 `POST`；`GET` 不接受请求体，查询参数通过 `--params`，POST 请求体通过 `--body`。
- `--body` 必须是有效 JSON；`--params` 必须是 JSON 对象；输入大小设置明确上限。
- 保留隐藏 `mbs raw` 作为开发兼容入口，不删除既有脚本依赖。
- `find → describe → request` 成为无预生成命令时的正式动态查询链路；已有专用命令仍可作为便利入口。
- 不新增后端接口，不修改网关权限、认证协议、Cookie 存储、业务响应或 npm 版本。

## 受影响范围

- `packages/cli`：公共 request 命令、输入校验及测试。
- `skills` 与 `scripts/gen-from-manifest.mjs`：动态执行协议及生成一致性。
- `README.md` 和全局 Skill 参考：公开使用说明。
- 审计索引与接口语义发现记忆。

## 输入与输出

示例输入：

```powershell
mbs request POST /yypms/pms/middlePanel/getMiddlePanelList --body '{"page":1,"pageSize":20}'
```

最终请求目标：

```text
<apiRoot>/gateway/cli/yypms/pms/middlePanel/getMiddlePanelList
```

成功和失败继续使用项目现有 JSON envelope 与退出码。

## 验收标准

1. GET/POST 相对路径可通过共享认证客户端发送，参数和请求体位置正确。
2. 绝对 URL、`//host`、路径穿越、控制字符、查询串、片段和未替换占位符在网络调用前被拒绝。
3. GET 请求体、非法 method、非法 JSON、非对象 params 和超限输入被拒绝。
4. `mbs request --help` 是公开命令，示例清楚说明 `/gateway/cli` 自动添加。
5. Skill 与生成器明确使用 `find → describe → request`，接口新增不再依赖预生成命令。
6. 生成一致性、定向测试、全量测试、构建和差异检查通过。
