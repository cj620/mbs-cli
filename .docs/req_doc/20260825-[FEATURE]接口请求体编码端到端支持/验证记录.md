## 已验证业务语义

- 支持 `NONE/JSON/FORM_URLENCODED/MULTIPART/TEXT/XML/BINARY`，旧无 `--api-id` 的 JSON GET/POST 调用保持兼容。
- 嵌套表单支持 `FLAT/DOT/BRACKET/JSON_STRING`；默认 `BRACKET + explode`，`explode=false` 的对象/带子节点数组为单个 JSON 字符串，标量数组为逗号连接单值。
- multipart 支持普通值、本地普通文件和严格 Base64；每个 part 可配置独立 Content-Type，文件名支持 `SOURCE_BASENAME/FIXED/OMIT`，boundary 仅运行时生成。
- TEXT/XML 只接受 UTF-8；BINARY 接受严格 Base64 或有界普通文件；任一输入、元数据或文件校验失败均不发送网络请求。
- CLI 不记录正文、文件内容、文件路径、Cookie 或响应；本地 serve 禁止通过请求值读取文件系统。
