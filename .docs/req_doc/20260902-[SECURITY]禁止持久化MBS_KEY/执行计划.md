## 恢复执行入口

- **任务目标**：禁止项目接触 `MBS_KEY`，并让 `mbs login --password` 通过终端隐藏输入直接取得认证中心 `SESSION`。
- **当前进度**：Cookie-only 认证、终端密码直登、旧 key 删除式清理、安全缓存、重新登录语义、测试与文档均已完成；全仓构建和测试通过。
- **下一步**：在目标 HTTPS 网关使用专用测试账号验证密码登录、二维码登录、业务只读请求和 Cookie 到期后的重新登录，再按发布流程交付。
- **阻塞**：无代码实现阻塞；真实 HTTPS 网关连通性与真实账号登录不在本地自动验证范围内。
- **待确认**：目标环境最终 HTTPS 外部根地址；不影响实现安全传输门禁和可配置路径。
- **未验证**：真实认证中心、真实 `SESSION` 与 `/gateway/cli` 的端到端兼容性。
- **重要警告**：不得为了兼容当前默认 HTTP 地址而允许非 loopback 明文密码登录。
- **执行授权**：已授权。
- **当前允许操作**：修改本仓认证代码、测试、文档，执行本地构建与测试。
- **当前禁止操作**：读取真实凭据、发送真实登录请求、修改其他项目、部署、发布、提交、推送或清理无关用户修改。
- **授权方式**：用户已明确要求修改，无需重复授权。
- **授权后的第一步**：已检查工作区，保留 `.idea/claudeCodeTabState.xml` 与此前认证规则文档修改。

## 风险与回滚

- 风险：目标环境未代理确认的认证中心路径。控制：路径集中为常量、只做本地 mock 验证，并在交付中标记真实联调未完成。
- 风险：现有自动刷新依赖被移除后，Cookie 到期会中断长任务。控制：返回明确退出码 2 和重新登录提示，不伪装重试成功。
- 风险：旧缓存用户结构与新安全摘要不同。控制：缓存读取时归一化最小安全字段，旧数据缺字段时安全失效。
- 风险：旧 key 清理会使旧版本 CLI 无法自动刷新。该影响正是安全整改目标；回滚代码不能恢复已经删除的本地 key，用户需重新登录。
- 回滚：代码与文档可按本任务差异逐文件恢复；不得恢复 key 捕获或持久化。若直登路径不可用，保留安全失败并继续使用不捕获 key 的 QR Cookie 登录。
- 数据保护：测试只使用明显无效的合成值；不读取本机认证配置，不发送真实认证请求。
- 上线前验证：目标 HTTPS 网关用测试账号完成密码登录、业务只读请求、Cookie 过期与重新登录验证。
- 上线后观察：认证成功率、401/退出码 2 比例、登录接口错误率；日志中不得出现密码、Cookie 或 key。

## 任务外发现

- 当前默认 `apiUrl` 使用远端 HTTP；密码直登必须由用户配置到目标 HTTPS 网关后才能使用。默认地址迁移涉及目标环境契约，本任务不猜测替换。
- 图谱包版本比技能文档新两个补丁版本；未安装或升级全局工具，图谱仅作导航。
