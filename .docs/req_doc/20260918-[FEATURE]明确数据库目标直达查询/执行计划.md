## 3. 已确认决策、执行假设与约束

- 目标是否明确由用户输入决定；只有完整只读 SQL 或明确物理表身份可以绕过语义发现。
- 业务别名和用途描述不视为物理表身份。
- 直达路径仍强制执行 `mbs database my-tables`，候选不是权限凭据，数据库命令继续接受后端二次鉴权和 SQL 安检。
- SQL 引用表无法唯一映射到同一数据源时暂停；不调用 `mbs find` 猜测，不自动换表。
- 用户提供 SQL 时保留其查询意图；若违反只读、显式列或结果限制规则，先收敛到安全查询或向用户说明，不能直接执行危险语句。
- 参数依赖自动解析、10 次 find 预算及现有未提交修改保持不变。

## 8. 风险与回滚

- **风险**：过宽识别“指定表”可能绕过有价值的语义召回。控制：只接受完整只读 SQL或明确物理表身份，业务别名仍 find。
- **风险**：SQL 中多个表映射到不同数据源。控制：要求全部表在 `my-tables` 中唯一解析且数据源一致，否则暂停。
- **风险**：与现有参数依赖任务差异重叠。控制：基于当前工作区增量修改并用定向测试保留其断言。
- **回滚**：反向恢复本任务对生成器、Skill、测试和记忆的新增差异；不涉及数据、配置、CLI 契约或远端状态。
