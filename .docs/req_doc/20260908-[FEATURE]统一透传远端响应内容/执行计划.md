## 设计约束

- 以共享层为深模块：集中定义 response body 的单次序列化和错误快照提取，命令适配器不重复识别错误类型。
- 透传 seam 只负责表达，不改变 APIClient 的认证刷新和退出控制。
- `find` 的远端结果不再进入候选归一化器；用户输入仍在发请求前校验。
- `describeApi` 保留为 `request --api-id` 的内部安全元数据解析；新增原始详情获取 seam 供 `mbs describe` 使用，避免输出路径复用解析器。
- serve 的本地路由与远端代理路由明确分离，只有后者适用上游 body 透传。
