## 风险、观察与回滚

- HTTP 风险：密码、Token、Cookie 与响应可能被监听或篡改；发布文档必须明确，服务端支持 HTTPS 后应重新配置。
- 发布风险：版本不可覆盖、标签不可复用；失败时停止，修复后重跑同一未发布版本的工作流，不强推或覆盖标签。
- 通道风险：维护发布只能使用 `maintenance-1`；发布前后核验 `latest` 未变化。
- 回滚：npm 版本不可删除覆盖；出现缺陷时以普通反向提交发布更高补丁版本，并可将 `maintenance-1` 指向已验证版本，任何 dist-tag 回调需重新授权。
- 观察：分支 CI、Release 作业状态、npm 精确版本、dist-tags、隔离安装后的命令与 Skill。
