## 恢复执行入口

- **任务目标**：支持扫码、账号密码和后台管理型长期 Refresh Token 三种登录入口，让显式及一次性自动刷新使用兼容交换，同时保持 `MBS_KEY` 禁令和 Access Token 仅内存边界。
- **当前进度**：三种登录入口、两类长期凭据互斥缓存、compat-session 交换和一次性业务重试均已实现，本地 V3 通过。
- **下一步**：如进入发布流程，使用脱敏测试账号在生产等价 HTTPS 网关执行独立联调。
- **阻塞**：无本地实现阻塞。
- **待确认**：目标生产 Origin、Cookie 属性和共享 Redis 兼容性仍由认证中心任务的生产等价验收负责，不阻塞本地客户端实现。
- **未验证**：真实 HTTPS 网关、真实 Cookie 轮换、Bearer/SESSION 兼容业务请求。
- **重要警告**：登录型 `AUTH_REFRESH` 每次交换都会旋转，管理型 `LongToken` 不轮换；响应解析或持久化失败后不得继续重放不确定状态。Access Token 禁止持久化或输出。
- **执行授权**：已授权。

## 执行前提与安全资产

- 受保护资产：账号密码、登录型 Refresh Token、短期 Access Token、SESSION 与用户身份。
- 不可信输入：CLI 选择与账号输入、认证中心响应、Set-Cookie、磁盘缓存和配置 URL。
- 失败行为：认证/响应契约失败默认拒绝；不回显响应正文或 Axios 请求配置；旋转不确定时清除本地缓存。
- 回滚：可逐文件恢复本任务差异，但不得恢复 `MBS_KEY` 捕获；已轮换凭据无法通过代码回滚恢复，需重新登录。

## 风险与回滚

- 登录型 Refresh 旋转使旧值立即不可用，客户端必须在成功响应中同时取得并落盘新 Refresh Cookie；管理型 LongToken 不轮换。
- 多个 CLI 进程并发使用同一登录型 Refresh Cookie 可能触发旧值重放保护并撤销登录族；本地进程内单飞无法覆盖跨进程并发，作为剩余风险披露。
- 真实网关可能改变 Cookie Domain/Secure/转发行为；本地只验证协议解析，发布前仍需生产等价联调。
- 回滚到 SESSION-only 代码不会恢复已轮换或已清除凭据；用户需重新登录，且禁止回滚到 `MBS_KEY` 方案。
